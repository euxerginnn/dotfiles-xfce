# dotfiles

Configurações pessoais do XFCE (Aspire Dev).

## O que está incluso

- XFCE4 (painel, atalhos, sessão, display)
- Picom (compositor)
- Plank + script de padding
- LightDM (tela de login)
- Temas GTK, ícones
- Autostart

## Uso

### Backup (salvar configs atuais)

```bash
./backup.sh
```

### Restore (aplicar configs em nova instalação)

```bash
./restore.sh
```

Faça logout/login após restaurar.
